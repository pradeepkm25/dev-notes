# 00 - Quick Capture Inbox

The Inbox is the entry point for all new technical discoveries, architectural realizations, and debugging breakthroughs.

---

## 🎯 Purpose

- **Zero Friction**: Dump unpolished notes in less than 2 minutes while coding.
- **Context Preservation**: Capture the discovery immediately so you can return to your task without losing focus.
- **Triage Pipeline**: Weekly, review active entries and move them to their permanent category folder.

---

## 🚀 How to Add a Note

1. Open [`INBOX.md`](file:///d:/Dhira-Work/dev-notes/00-INBOX/INBOX.md).
2. Copy the template block from [`templates/quick-note-template.md`](file:///d:/Dhira-Work/dev-notes/templates/quick-note-template.md).
3. Paste at the top of the **Active Captures** section.
4. Fill in Date, Title, Discovery, Where it can be useful, Action, and Tags.
5. Save and get back to coding!
